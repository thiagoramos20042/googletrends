# Google Trends | Exploração de tendências de busca

Exploração de um conjunto histórico de tendências de busca, com filtros por região, ano e categoria.

**Análise de dados** · Notebook

[← Portfólio de Thiago Oliveira](https://github.com/thiagoramos20042/thiagoramos20042) · [Catálogo de projetos](https://github.com/thiagoramos20042/thiagoramos20042/blob/main/PROJETOS.md)

## Objetivo

Investigar quais assuntos e categorias aparecem no histórico de buscas, incluindo o recorte brasileiro do estudo.

## O que você encontra

- Leitura e exploração do conjunto histórico.
- Filtros por país, ano, categoria e assunto.
- Rankings e organização das principais buscas por categoria.

## Tecnologias

Python · pandas · NumPy · Matplotlib

## Como explorar

Abra [Google_Trends.ipynb](Google_Trends.ipynb) no visualizador do GitHub para acompanhar o código e as saídas salvas. Para explorar as células, use Jupyter ou a extensão de notebooks do VS Code. Antes de executar, confira os caminhos de entrada, as fontes externas e os imports nas primeiras células.

## Contexto do projeto

Os resultados se referem ao dataset histórico usado no notebook; o projeto não é um painel de buscas em tempo real.
